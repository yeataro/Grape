Graph performs admission and atomic publication; module callbacks never resolve native paths or obtain Target authority. Same Graph and load reuse happens before narrower clipboard admission. The shipped source owner implements numeric constant/uniform transfer, native float/vec2/vec3/vec4 arrays with literal or typed symbolic extents, sampler descriptors, TOP source+origin slot reuse, and specialization minimum-vacancy IDs. Legacy v1 input aliases are not treated as native paths or silently converted; the accepted S02 legacy boundary is retained.

The numeric ES300 emitter explicitly reports runtime-unavailable for nonconstant source emission; sampler types are profile-unavailable. These are portable descriptor admission/transfer results, not claims of real TD resource resolution.
