這一批改了什麼

  • 多視圖編輯：在 Project actions 開啟 Second Canvas 與 Add Parameters。各 Canvas 保留自己的選取、導覽與視角，編輯共用同一份圖及 Undo。
  • Parameters 跟隨來源：從頁籤的 Panel options 或底部 Panels → Settings 調整 Source、Link group。群組 0 跟隨最近啟用的 Canvas；其他群組只跟同組來源。
  • 版面調整：拖拉頁籤移動與分組，或使用 Move／Split／排序操作。分隔線可拖曳，或用方向鍵、Shift、Home／End；Escape 取消這次調整。
  • 浮動 Parameters：Float Parameters 會放到右上方，可收合、調寬或回到原停靠區。P 快捷鍵保留文字輸入與 IME 的守衛。
  • 保存目前版面：Save current layout 與 Restore／Export／Import 保存工作區，不影響圖的 Undo 或儲存狀態。恢復後點選 Canvas，重新指定目前操作來源。
