拖曳修正與四種固定值節點

這是目前 S05 的這一批實機測試。先測拖曳，再看新節點；S05 整體仍在進行。

1. 拖曳是否順暢

下載 Multiply 拖曳範例 · 下載 Image Output 對照範例

  1. 先保存手上有修改的文件。在測試畫面按 Open file，選剛下載的 Multiply 範例。
  2. Review document 顯示 DOCUMENT_VALID 後，按 Open in new session。
  3. 選取 Multiply，讓右側 Inspector 顯示 A、B。連續拖曳幾次，確認節點跟隨游標，A、B 數值保持不變。
  4. 放開後按一次 Undo，應回到這次拖曳前的位置；Redo 應恢復。再次拖曳時按 Escape，應取消這次拖曳。
  5. 用同樣方式開啟 Image Output 對照範例，拖曳 Image output，感受两者是否都可正常操作。

兩份圖都是 14 節點；其中 10 個未連線節點在畫面外，用來增加同樣的圖資料量。自動量測的改善不等於所有裝置都保證相同 FPS，這裡請以你的實際拖曳感受判斷。

2. 四種固定值節點

開新文件，或從下表下載範例，以 Open file → Open in new session 開啟。

按鈕／節點預設值範例下載
Add Float (fixed)0.5Float
Add Vector 2X/Y：0.5、0.5Vector 2
Add Vector 3X/Y/Z：1、1、1Vector 3
Add Color RGBAR/G/B/A：0.55、0.28、0.9、1Color RGBA
  1. 選取節點，修改 Inspector 的數字並按 Enter。可依序試 0.125、0.375、0.625、0.875，只填該節點有的欄位。
  2. 按 Undo／Redo，確認最後一次編輯能還原及重做。按 Save，再用 Open saved 重新開啟，數值應保留。
  3. 範例已接好 Image output；按 Generate GLSL，應看到 Generated successfully · Host-free GLSL。

新 Float 請選 Add Float (fixed)。舊的 Add Float 仍維持原有行為。輸出型別分別為 float、vec2、vec3、vec4，接線不改變來源節點型別。

3. 子圖與 Vertex（需要時可補測）

Vector 2 共用 Function 範例：選 Subgraph → Enter subgraph，選裡面的值節點後改 X/Y，再試 Undo／Redo、Save／Open saved 與 Generate GLSL。共用呼叫應保持一致。

Vertex 工作區：開啟後可新增本批四種固定值節點，將 out 接到 Position 子圖的 Value，再 Generate GLSL。其他節點仍依既有 Stage 設定限制。

ZIP 中 samples 是新固定值範例，performance 是拖曳範例，legacy-samples 保留之前的 S05 範例。

你先前已確認的 Replace 部分不用整套重測。不同模組或輸出設定的文件會停用 Replace，這時使用 Open in new session 即可。
