GROUP FRAME · VISUAL ORGANIZATION

框住一組節點，保留原本的圖。

Group Frame 是有名字、顏色與明確成員的視覺群組。它讓使用者一起選取、移動與整理節點；線仍直接連到原來的節點，框沒有輸入／輸出接口。

SOURCE-DERIVED 以下規則由 Legacy 原始碼與既有測試內容整理；協作主代理另觀察到 Pixel Output 框的標題、更名、色點、移除框與角落選取入口。手勢細節仍標為 Source-derived。圖中樣式為局部重繪，互動只發生在本頁。

01 / FRAME

Group Frame

同一張圖上的視覺組織。成員仍可個別選取、移動與接線；移除框會留下節點和線。

Create group frame Ctrl / Cmd + G
02 / SUBGRAPH

Subgraph

把可提取的節點與內部連線放進另一張圖，建立 Input／Output 與呼叫節點。這是一個改變圖結構的獨立操作。

Selection to subgraph Ctrl / Cmd + Shift + G

G02 / EXPLICIT MEMBERS

成員關係要明確

  • 建立框需至少兩個尚未屬於任何框的節點。
  • 節點在同一張圖只屬於一個框；框不以另一個框作為成員。
  • Join 依選取中「已有成員數最多」且沒有平手的框決定目的地；沒有目的地、平手或沒有新成員時不可用。
  • Detach 只解除選中節點的成員關係；位置、值與線保留。單一成員的框可保留，最後一位離開後框消失。
G03 / AUTO BOUNDS

範圍跟著成員走

  • 使用成員卡片目前的顯示範圍，加上四周 24 graph-space px 與上方 28 px 標題高度。
  • 個別成員移動、調整大小或收合，框會跟著重算；框本身沒有自由拖拉尺寸的接口。
  • 右下角弧線是「選取全部成員」入口，不是 resize。
  • 框空白區讓命中測試穿透到 Canvas；拖曳移動群組的區域是標題列。
G04 / COLLAPSE & REMOVE

收合成員；移除框

  • Legacy 沒有獨立的「整個 Group Frame 收合成一張卡」狀態。
  • 選取全部成員後，可用既有 Collapse／Expand 操作收合或展開支援的節點；連線與成員關係不變。
  • 框標題的 × 移除框；成員節點與連線留下。選取成員後的 Delete 是刪節點，兩個動作不同。
  • 框本身沒有 Shader socket，也不替成員產生新的資料邊界。
G05 / CAPABILITY & ENTRY

保留能力，入口與顯示設定分開。

能力／效果Legacy 入口參考顯示與配置的界線
建立、加入、移出視覺群組選取工具列／Graph actions；Mod+G、Alt+Shift+G、Alt+G工具列位置可配置；可用性仍取決於選取與明確目的地。

保留與搬運群組標示文件保存；完整成員 Copy／Paste；提取 Subgraph。複製全部成員才附帶 Frame；部分複製不附帶。完整 Frame 可隨成員進入 Subgraph，仍只在所屬圖顯示。
